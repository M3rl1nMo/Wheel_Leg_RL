# 停稳计时价值网络与小规模 PPO

入口 `RL/archive/code/direct_clock_ppo.py`，独立保存实验，原有策略和控制程序保持可运行。

## 本轮要检查的问题

成功条件包括连续两秒处于距离3cm、速度0.03m/s、转向角速度0.1rad/s以内。原27维观测没有连续停稳计时，同一物理状态可能因计时不同而有不同的未来成功奖励。本轮仅给价值网络增加第28项 `min(streak * dt / 2, 1)`；策略始终读取前27项，仍然使用SiLU、直接输出六个力矩的分布参数。

`critic_obs` 拼接价值网络专用观测。`ActorView` 在复用PPO更新函数时取前27项，确保计时不会进入策略。计时来自环境真实记录，条件被破坏时环境将其清零，恢复状态开启新回合时也清零。

## 校准对照

使用上轮真实状态库，冻结原模仿策略，标准差0.01，从每个起点继续运行最多80秒。前20秒每0.02秒采样，奖励反向折扣累积，不用价值预测填补尾部。训练14、验证5、测试5个起点，测试每点三个种子。

27维对照价值网络和28维价值网络均从上轮校准权重初始化；新增输入的权重初始化为零，因此起初预测完全相同。两者使用同一数据、随机种子、200遍训练预算、每轨迹等权损失；分别按验证误差选择权重。若新增计时没有改善验证误差，则停止并保存结果，不执行策略更新。

## 小规模策略更新

校准门槛通过后进行4次PPO更新，每次32768步。14个训练起点各采约2340步（4.68秒），每个片段独立计算优势，不跨起点串联；片段末尾用下一状态价值补尾，真正成功或摔倒不补尾。若片段内回合结束，从同一起点重新开始。

GAE的lambda改为 `exp(-dt/2)`，gamma仍为 `exp(-dt/10)`。GAE是用连续若干步的奖励与价值预测误差计算动作优势的方法；此处将lambda对应的时间从0.5秒延长到2秒，使较后面的奖励对当前优势影响更大。联合gamma后实际衰减时间约1.67秒，并非完整保留所有两秒内奖励。

策略学习率1e-5、价值学习率0.0003、动作标准差0.01，复用原PPO裁剪、参考策略约束和KL提前停止。奖励不变。训练起点只读取状态库train组。验证使用原4个任务选择候选，最终在原8个40秒任务检查站立、到点停稳和距离；不通过保留基线的筛选条件就导出原策略。

这是一组组合修改后的探索性实验，不能把控制结果归因于单独的计时输入。短片段普通起点覆盖有限；状态库范围也很小。测试任务此前已经被反复查看，不是全新泛化测试。校准目标中的成功终止与40秒评估中的持续保持也不同，因此实际效果必须通过持续运行评估确认。

验证选择第2次更新。最终原8任务40秒测试：基线与候选均6/8站立、2/8停稳；转圈任务末两秒平均转向角速度 0.6890→0.6868 rad/s，未实质解决。部分距离残差变差，如任务4从4.22cm变为4.77cm。候选未通过筛选，exported_iteration=0，selected_policy.pt恢复为基线。训练成功回合增加也可能来自重复准备停稳起点，不能当作从普通起点学会任务的证据。

本轮只证明增加计时降低当前价值数据集误差，没有证明策略获得整体改善。新增输入、真实起点混合采样、延长GAE一起进入PPO，不能独立归因。后续宜检查转圈/残差类别的动作优势是否能区分改善动作，扩展这两类真实状态与有效探索；当前证据不足以认定网络层数是原因，也不支持直接大量延长同配置训练。

通过测试：新增2项（计时与策略输入隔离、混合采集到PPO反向更新），既有PPO3项；状态恢复2项在上一阶段已通过。全部原权重保持，候选独立保存。结果副本为 results/direct_clock_ppo_report.json、direct_clock_critic_candidate.pt、direct_clock_ppo_selected.pt；28维价值模型的使用方必须按 critic_dim=28 创建网络。
