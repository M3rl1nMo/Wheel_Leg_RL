# 平面目标控制与 24 维策略

日期：2026-10-29。实现与验证位于 `planar_control.py`、`planar_navigation.py`。

## 运行已训练策略

项目根目录中运行（坐标单位米，初始朝向单位弧度）：

```powershell
& '.\.venv\Scripts\python.exe' '.\RL\planar_navigation.py' --evaluate --checkpoint '.\RL\results\planar_policy.pt' --target-x 0.2 --target-y 0.2 --seconds 40 --viewer
```

去掉 `--viewer` 可无窗口运行；`--initial-yaw 1.0` 设置初始朝向。此入口仅在内存中禁用原模型的斜坡碰撞和显示，构成无障碍平面实验，不修改原 XML。没有路径规划或避障功能。

直接查看 LQR 教师（不加载网络）：

```powershell
& '.\.venv\Scripts\python.exe' '.\RL\planar_navigation.py' --teacher --target-x 0 --target-y 0.3 --viewer
```

## 控制过程

1. 世界坐标目标减当前位置，按当前 yaw 旋转到机身坐标，得到前方、左侧位置误差。
2. 平面外环使用位置误差和有限积分计算前进指令（±0.15 m/s），用朝向误差计算转向指令（±0.6 rad/s）。方向偏差大时减少前进指令。
3. 距离小于 0.025 m 时冻结目标朝向，继续纠正纵向偏差；距离重新超过 0.15 m 才退出保持状态，避免因过渡摆动频繁重新转向。这不保证横向误差严格收敛到零，当前采用 0.03 m 到达容差。
4. 网络根据状态与指令输出六路力矩，仍使用 `tanh` 和原力矩限制。

**执行时保留手写平面位置外环，六路执行力矩来自神经网络。** LQR 作为教师为采集轨迹计算标签，不混合下发动作，不在评估期间更新参数。

新教师直接读取 IMU `angular_vel[2]` 作为绕 z 的角速度。原辅助函数中的 `gyro_yaw` 实际取 x 分量，不适用于这里的转向反馈；原控制器文件没有被改动。

输入为原 20 维观测，追加前方位置误差、左侧位置误差、目标前进速度、目标转向速度，共 **24 维**。前两项尺度为 0.5 m，后两项为 0.15 m/s、0.6 rad/s。网络仍为 `24 → 32 → SiLU → 6`。时间观测继续按 3 秒计算，3 秒之后为零。

## 训练与验证

从已验证的 22 维 x 控制模型迁移参数，新侧向与转向输入初始权重为零。先采集 LQR 轨迹，再追加两轮网络自身轨迹的 LQR 标签。总训练数据 360000 条，验证数据 90000 条；每轮训练 60 遍，Adam 学习率 0.0003、批次 256。按验证损失选择参数，测试轨迹不参与梯度更新。

训练目标覆盖半径 0.15/0.3 m 的前后、左右和斜向位置。模型与初始化模型分别保存在 `results/planar_policy.pt`、`results/x_position_policy.pt`。

固定五组目标和初始朝向，每组运行 40 秒，最终模型全部未摔倒且到达停稳。五个最终距离误差为 0.00086、0.01863、0.02204、0.01778、0.02164 m。

重新加载最终模型后，用独立随机种子 20261029 生成 8 组测试：目标半径从 0.15–0.6 m 范围采样、初始 yaw 从 [-pi,pi] 采样，全部通过。最终距离误差为 0.01077–0.02406 m。

停稳判据要求整个仿真无摔倒，最后 **连续 2 秒**同时满足：

- 到目标的平面距离 ≤ 0.03 m。
- 机身平面速度 ≤ 0.03 m/s。
- IMU 绕 z 角速度绝对值 ≤ 0.1 rad/s。

验证报告见 `results/planar_report.json` 和 `results/planar_holdout.json`。固定测试用于阶段性观察；随机测试在最终模型冻结后执行。有限目标测试不构成任意距离、任意状态下的保证；更远目标、强扰动、障碍物、连续目标切换和实机均未验证。

## 2026-10-29：保持模式切换时匹配前一步速度指令

针对 PPO 候选在补充目标附近的停稳延迟，修改 `planar_control.py`：记录前一物理步传给策略的目标速度 `previous_velocity`。仅在首次切入保持模式时，根据当前前向误差 f 反算积分 `I=clip((previous_velocity-f)/0.6,-0.2,0.2)`，该步不额外累加位置误差；后续步骤继续正常积分。这样在积分限幅允许时，`f+0.6*I` 与上一步目标速度相同，避免取消朝向衰减后目标速度突然增大。若所需积分超出限幅，保留积分安全边界，不能保证完全连续。转向指令、其他控制参数和神经网络权重未改。

这是通用切换规则，不使用诊断中参考轨迹的 0.1244 常数，也不把积分每步清零。每次创建控制器时，上一速度初始化为 0。

原 SiLU 模型和 PPO 第 13 次候选分别测试 8 个已有目标、每个运行 40 秒，均为 8/8 到点并停稳；LQR 教师同样 8/8。平均停稳时间：原 SiLU 17.8205→15.0950 秒，PPO 候选 18.8930→15.7255 秒。原 SiLU 姿态 RMS 0.00527139→0.00524586 rad，归一化力矩变化率 RMS 4.63537→4.63094 /s；PPO 对应 0.00548107→0.00545072 rad、4.66990→4.66391 /s。没有重新训练网络。修正后原模型仍优于这个 PPO 候选的平均到达时间，默认继续使用原模型。
