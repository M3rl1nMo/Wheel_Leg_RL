# 同状态动作优势诊断（2026-10-29）

实验：experiments/action_advantage_20261029_175929/report.json。脚本 diagnose_action_advantage.py。未更新任何网络或默认gamma。

固定原模仿策略与28维校准价值网络，使用测试状态库中一个spin和一个slow起点。每点比较9个动作：均值基线、两轮raw动作同号/异号的正负0.01及0.1变化；只改变第一个0.002秒动作，随后回到原策略，标准差0.01。每个动作三个相同随机种子配对续跑30秒，共54条轨迹。

对比单步TD误差的变化与实际30秒折扣回报的变化。TD是GAE的组成项，不等同于PPO最终使用的多步GAE优势。30秒回报未补尾，对持续转圈不是无限时域精确回报；只测试两轮方向和两个状态，不能推广到整个状态空间。

转圈：同号+0.1动作的TD变化+0.2013，实测回报变化+0.0002369，三种子均正。存在严重幅度不匹配，部分微小动作排序还受噪声影响。不能认定全部动作方向都错。

慢速残差：同号+0.1动作的TD变化-0.3760，实测回报变化均值+0.1764，三次分别+0.5123、+0.01689、-0.0000004；异号-0.1的TD变化-0.1374，实际均值+0.1724。提示局部评分可能反向，但均值受单个随机续跑主导，尚需更多种子及完整GAE检查。此类较大动作是10倍训练标准差，也包含分布外价值预测风险。

结论：本诊断找到了值得进一步检查的动作敏感性和局部排序问题，不是一次改善控制的训练。下一步优先记录配对续跑的完整GAE，扩大随机种子，比较延长动作持续时间能否提高有效动作信号，不能仅凭本次两状态结果直接调整整个训练。
