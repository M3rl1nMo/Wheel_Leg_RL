# 独立 27 维策略的 PPO 距离与停稳实验

入口 `RL/direct_ppo.py` 从 `results/direct_imitation_candidate.pt` 初始化，保持 27→32(SiLU)→6 结构。动作完全由网络生成，不计算 LQR 教师标签，不创建位置外环。仅从 `planar_ppo.py` 复用 GAE 和 PPO 优化函数；没有使用它的外环环境、教师或采集入口。

## 奖励定义

距离 d 的单位为米，dt=0.002 s，gamma=exp(-dt/10)≈0.999800。定义距离评分 `S(d)=0.05/(d+0.05)`，以及近目标系数 `q=S(d_next)^2`。每步奖励分量为：

| 分量 | 每步数值 |
| --- | --- |
| 普通距离改善 | `2 * (d_old-d_next)` |
| 非线性评分变化 | `gamma*S(d_next)-S(d_old)` |
| 耗时 | `-0.2*dt` |
| 姿态波动 | `-0.5*(pitch²+roll²)*dt` |
| 近目标移动 | `-0.05*q*(speed/0.1)²*dt` |
| 近目标转动 | `-0.05*q*(yaw_rate/0.3)²*dt` |
| 力矩变化率 | `-0.000005*mean((u_next-u_old)²)/dt` |
| 首次连续满足停稳要求 | `+5` |
| 摔倒 | `-10` |

u 为各电机力矩除以其限幅后的归一化值。力矩变化率权重采用用户希望尝试的较低值，为先前 0.00002 的四分之一。本轮同时新增了 PPO 和多个奖励项，不能用结果单独归因于降低力矩权重；严格权重对照尚需另做。

非线性评分在 0～1 之间，距离为零时不发散。在目标附近，同样距离缩短导致更大的评分提升。实际使用折扣势函数形式，静止时该项有很小的非正值，不是每步支付完整距离评分。真正结束（摔倒、训练中成功）后的吸收状态评分取 0；时间截断不是终止，保留下个评分和价值 bootstrap。测试校验了该项的折扣求和关系和终止处理。

成功条件没有放宽：距离≤0.03 m，平面速度≤0.03 m/s，转向角速度绝对值≤0.1 rad/s，连续满足 2 秒。训练达到条件就结束并重置；确定性评估继续到 40 秒，要求最后 2 秒仍满足。摔倒阈值仍为俯仰/横滚绝对值超过 0.8 rad 或机身高度低于 0.12 m。

## 训练与筛选

随机种子 72，探索正态分布标准差 0.01。每批 8192 步，最多 12 次策略更新。策略学习率 1e-5，价值学习率 0.0003，PPO 比值裁剪 ±0.1，每批最多更新 4 遍，小批次 512，梯度范数限制 0.5。每遍开始前检查 KL 差异，过大则停止后续遍历。

保留与初始策略分布的弱 KL 惩罚（权重 0.01）以限制初期偏离；这不使用教师动作标签。价值网络是新建 27 维输入网络，先固定策略采集两批、每批训练价值网络 20 遍，再进入策略更新。预训练目标是 GAE 计算的带 bootstrap 目标，并非完整真实回报；拟合误差下降不表示价值预测已经准确。摔倒经历照常学习，不要求先在所有任务成功。

训练使用模仿实验的 12 组目标与初始朝向。每次更新后以原来 4 个验证任务评估，先比较站立数，再比较到点数，最后比较平均终点距离；候选还必须保留基线中每个已站立/已停稳任务的相应能力。其他候选记录并保存，但不作为最终替换模型。

最终只对按验证集选出的候选执行 8 个回归测试。若测试未保留原有能力或没有改善，最终导出回退为原模仿模型，`exported_iteration=0`。原始模仿文件始终不覆盖。此前已用过这些测试任务，结果不是全新未知任务的泛化证明。

## 运行

```powershell
& '.\.venv\Scripts\python.exe' '.\RL\direct_ppo.py' --iterations 12 --steps 8192 --std 0.01
```

每次新建 `experiments/direct_ppo_时间戳/`，保存候选、JSON 报告和 `selected_policy.pt`。当前入口每次重新从模仿模型开始，不支持完整恢复中断的训练；检查点中保存优化器信息不等于已有恢复入口。

评估导出的模型仍用 `direct_navigation.py --evaluate --checkpoint PATH --viewer`。应先查看报告中的 `selected_iteration`、`exported_iteration` 和实际测试成功率，不能把候选存在视为训练成功。

检查命令：`python RL/test_direct_ppo.py`。已检查评分边界、终止后的势能、GAE 终止/截断区别、没有外环/教师构造、实际上一动作反馈。
